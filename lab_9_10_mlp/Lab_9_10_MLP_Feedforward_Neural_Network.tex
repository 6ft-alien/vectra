working.

classification of legal vs.~illegal remote desktop sessions based on
mouse movement patterns.

\subsection{Section 2: MLP Architecture (From
Scratch)}\label{section-2-mlp-architecture-from-scratch}

We implement a configurable Multi-Layer Perceptron with: - Arbitrary
number of hidden layers and neurons - Xavier weight initialization -
Forward pass with cached intermediate values (for backpropagation)

\subsubsection{Architecture Diagram}\label{architecture-diagram}

    \subsubsection{2.1 Weight Initialization}\label{weight-initialization}

We use \textbf{Xavier (Glorot) initialization} for Sigmoid/Tanh and
\textbf{He initialization} for ReLU:

\begin{itemize}
\tightlist
\item
  \textbf{Xavier:}
  \(W \sim \mathcal{N}\left(0, \frac{2}{n_{in} + n_{out}}\right)\)
\item
  \textbf{He:} \(W \sim \mathcal{N}\left(0, \frac{2}{n_{in}}\right)\)
\end{itemize}

\subsection{Section 3: Activation
Functions}\label{section-3-activation-functions}

Activation functions introduce \textbf{non-linearity} into the network,
enabling it to learn complex, non-linear decision boundaries.

Without non-linear activations, an MLP of any depth reduces to a single
linear transformation:
\(f(x) = W_L \cdot W_{L-1} \cdots W_1 \cdot x + b = W'x + b'\)

\subsubsection{3.1 Sigmoid}\label{sigmoid}

\[\sigma(z) = \frac{1}{1 + e^{-z}}, \quad \sigma'(z) = \sigma(z)(1 - \sigma(z))\]

\subsubsection{3.2 Tanh}\label{tanh}

\[\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}, \quad \tanh'(z) = 1 - \tanh^2(z)\]

\subsubsection{3.3 ReLU}\label{relu}

\[\text{ReLU}(z) = \max(0, z), \quad \text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}\]

\subsubsection{3.4 Linear (Identity)}\label{linear-identity}

\[f(z) = z, \quad f'(z) = 1\]

\subsection{Section 4: Loss Function --- Binary
Cross-Entropy}\label{section-4-loss-function-binary-cross-entropy}

For binary classification, we use \textbf{Binary Cross-Entropy (BCE)}
loss:

\[\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]\]

where \(y_i \in \{0, 1\}\) is the true label and
\(\hat{y}_i \in (0, 1)\) is the predicted probability.

\subsubsection{Gradient of BCE with respect to
prediction:}\label{gradient-of-bce-with-respect-to-prediction}

\[\frac{\partial \mathcal{L}}{\partial \hat{y}_i} = -\frac{y_i}{\hat{y}_i} + \frac{1 - y_i}{1 - \hat{y}_i}\]

When the output activation is \textbf{sigmoid}, the combined gradient
simplifies elegantly:

\[\frac{\partial \mathcal{L}}{\partial z^{(L)}} = \hat{y} - y\]

\subsection{Section 5: Backpropagation
Algorithm}\label{section-5-backpropagation-algorithm}

Backpropagation computes the gradient of the loss with respect to every
weight and bias in the network using the \textbf{chain rule}. These
gradients tell us how to adjust each parameter to reduce the loss.

\subsubsection{Derivation}\label{derivation}

Consider a network with \(L\) layers. For layer \(l\): -
\textbf{Pre-activation:} \(z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}\) -
\textbf{Activation:} \(a^{(l)} = g^{(l)}(z^{(l)})\)

\paragraph{Step 1: Output Layer Error}\label{step-1-output-layer-error}

For the output layer \(L\) with sigmoid activation and BCE loss:

\[\delta^{(L)} = \frac{\partial \mathcal{L}}{\partial z^{(L)}} = a^{(L)} - y\]

\paragraph{Step 2: Hidden Layer Error (propagate
backwards)}\label{step-2-hidden-layer-error-propagate-backwards}

For hidden layer \(l\) (from \(L-1\) down to \(1\)):

\[\delta^{(l)} = \left( W^{(l+1)T} \delta^{(l+1)} \right) \odot g'^{(l)}(a^{(l)})\]

where \(\odot\) denotes element-wise multiplication.

\paragraph{Step 3: Parameter
Gradients}\label{step-3-parameter-gradients}

\[\frac{\partial \mathcal{L}}{\partial W^{(l)}} = \frac{1}{N} \delta^{(l)} \cdot a^{(l-1)T}\]

\[\frac{\partial \mathcal{L}}{\partial b^{(l)}} = \frac{1}{N} \sum \delta^{(l)}\]

\subsection{Section 6: Training with Gradient
Descent}\label{section-6-training-with-gradient-descent}

\textbf{Gradient Descent} iteratively updates the network parameters to
minimise the loss:

\[W^{(l)} \leftarrow W^{(l)} - \eta \frac{\partial \mathcal{L}}{\partial W^{(l)}}\]

\[b^{(l)} \leftarrow b^{(l)} - \eta \frac{\partial \mathcal{L}}{\partial b^{(l)}}\]

where \(\eta\) is the \textbf{learning rate}.

We use \textbf{mini-batch gradient descent} which processes small
batches of samples at each step, balancing the stability of batch GD
with the speed of stochastic GD.

    \subsubsection{7.5 Demonstrating the Necessity of
Non-Linearity}\label{demonstrating-the-necessity-of-non-linearity}

The table above shows that the \textbf{LINEAR activation} (no
non-linearity) performs significantly worse than the non-linear
activations. This is because:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{A deep linear network is equivalent to a single linear layer:}
  \(f(x) = W_3 W_2 W_1 x + b = W' x + b'\)
\item
  The decision boundary of a linear model is a \textbf{hyperplane} ---
  it cannot capture the complex, non-linear patterns in mouse dynamics
  data.
\item
  Non-linear activations (Sigmoid, Tanh, ReLU) allow the network to
  learn \textbf{hierarchical, non-linear features} that distinguish
  legal from illegal sessions.
\end{enumerate}

\subsection{Conclusion}\label{conclusion}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{MLP Architecture:} We implemented a configurable feedforward
  neural network from scratch using NumPy with support for arbitrary
  layer configurations.
\item
  \textbf{Activation Functions:} Sigmoid, Tanh, and ReLU were
  implemented with their derivatives. ReLU generally converges faster
  due to mitigating the vanishing gradient problem, while Sigmoid and
  Tanh can suffer from saturation.
\item
  \textbf{Non-Linearity is Essential:} The linear activation experiment
  clearly demonstrated that without non-linear activation functions,
  even deep networks cannot learn complex patterns --- they collapse to
  a single linear transformation.
\item
  \textbf{Binary Cross-Entropy Loss} was used as the cost function,
  appropriate for binary classification tasks.
\item
  \textbf{Backpropagation} was derived step-by-step and implemented to
  compute gradients efficiently via the chain rule, propagating error
  signals from the output back through hidden layers.
\item
  \textbf{Gradient Descent} (mini-batch) was applied to iteratively
  minimise the loss function by updating weights in the direction of
  steepest descent.
\item
  \textbf{Comparative Analysis} showed the training dynamics and final
  performance across different activation functions, with non-linear
  activations significantly outperforming the linear baseline.
\end{enumerate}
