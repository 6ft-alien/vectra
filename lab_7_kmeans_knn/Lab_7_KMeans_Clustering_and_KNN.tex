    \subsection{3. Supervised vs Unsupervised Learning:
Justification}\label{supervised-vs-unsupervised-learning-justification}

\subsubsection{Does the dataset contain labeled
classes?}\label{does-the-dataset-contain-labeled-classes}

\textbf{Yes.} The \texttt{is\_illegal} column provides binary
ground-truth labels: - \texttt{0} $\rightarrow$ Legitimate session (user is who they
claim to be) - \texttt{1} $\rightarrow$ Illegitimate session (imposter attempting to
mimic the legitimate user)

\subsubsection{What is the objective?}\label{what-is-the-objective}

The research objective is \textbf{binary classification}: given a set of
behavioral features extracted from a mouse session, predict whether the
session belongs to the legitimate user or an imposter. This is
fundamentally a \textbf{supervised learning} problem.

\subsubsection{Why Supervised Learning (KNN) is More
Appropriate}\label{why-supervised-learning-knn-is-more-appropriate}

\subsubsection{Conclusion}\label{conclusion}

Since our dataset contains \textbf{explicit labeled classes} and the
research objective is to \textbf{classify sessions as legitimate or
illegitimate}, a \textbf{supervised learning approach (KNN)} is clearly
more appropriate. K-Means, being unsupervised, would ignore the
available labels and attempt to discover natural groupings that may not
align with the authentication task.

However, we will implement \textbf{both algorithms} for empirical
comparison as required by this lab.

    \subsection{6. K-Nearest Neighbors (KNN)
Implementation}\label{k-nearest-neighbors-knn-implementation}

KNN is a supervised, non-parametric classifier that assigns a class
based on the majority vote of its K nearest neighbors in feature space.
For our behavioral biometrics dataset:

\begin{itemize}
\tightlist
\item
  \textbf{Distance metric:} Euclidean (on standardized features)
\item
  \textbf{Feature scaling:} StandardScaler applied (critical for KNN)
\item
  \textbf{Optimal K selection:} 5-fold cross-validation over K = 1 to 30
\end{itemize}

    \subsection{8. Observations and
Conclusion}\label{observations-and-conclusion}

\subsubsection{Key Findings}\label{key-findings}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Dataset Characteristics:} The Balabit Mouse Dynamics dataset
  contains \textbf{explicitly labeled classes} (\texttt{is\_illegal}: 0
  or 1), making it a \textbf{supervised binary classification} problem.
  The objective is to predict whether a session is legitimate or
  illegitimate based on behavioral features.
\item
  \textbf{Supervised vs Unsupervised:} Since labeled ground truth is
  available and the goal is class prediction (not pattern discovery),
  \textbf{supervised learning (KNN)} is the appropriate approach.
  K-Means ignores labels and attempts to find natural clusters, which
  may not correspond to the authentication classes.
\item
  \textbf{K-Means Limitations:} The K-Means clustering (K=2) produced
  clusters that poorly aligned with the true labels, as confirmed by a
  low Adjusted Rand Index. This is expected because:

  \begin{itemize}
  \tightlist
  \item
    Behavioral features of legitimate and illegitimate users overlap in
    high-dimensional space
  \item
    K-Means assumes spherical, equally-sized clusters; behavioral data
    rarely satisfies these assumptions
  \item
    The cluster assignment is arbitrary and requires post-hoc label
    mapping
  \end{itemize}
\item
  \textbf{KNN Superiority:} KNN leverages the available labels directly,
  producing significantly better classification performance. The optimal
  K was selected via cross-validation, balancing overfitting (small K)
  and underfitting (large K).
\item
  \textbf{Practical Implications:} For Zero-Trust Architecture
  deployment:

  \begin{itemize}
  \tightlist
  \item
    KNN provides \textbf{direct accept/reject decisions} for real-time
    authentication
  \item
    Feature scaling is critical (StandardScaler) since KNN is
    distance-based
  \item
    The model can be updated incrementally as new behavioral data is
    collected
  \end{itemize}
\end{enumerate}

\subsubsection{Algorithm Selection: KNN (K-Nearest
Neighbors)}\label{algorithm-selection-knn-k-nearest-neighbors}

KNN is selected as the most appropriate algorithm because: - The dataset
has labeled classes, so supervised learning is applicable - KNN achieves
superior classification accuracy over K-Means - It provides
interpretable, actionable predictions for the authentication pipeline -
It aligns with the research objective of continuous user verification in
ZTA
