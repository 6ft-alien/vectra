    \section{Lab 6.1 --- Decision Tree and Random
Forest}\label{lab-6.1-decision-tree-and-random-forest}

\textbf{Dataset:}
\href{https://archive.ics.uci.edu/dataset/373/drug+consumption+quantified}{Drug
Consumption (Quantified)} --- UCI Machine Learning Repository (id 373)

Direct download (zip):
https://archive.ics.uci.edu/static/public/373/drug+consumption+quantified.zip

\textbf{About the dataset:} 1,885 respondents were measured on
personality traits and demographics, then asked about lifetime use of 18
legal/illegal substances (Fehrman, Egan \& Mirkes, 2015, \emph{``The
Five Factor Model of personality and evaluation of drug consumption
risk''}). All 12 predictor columns are already numeric (``quantified'')
with \textbf{zero missing values}, which keeps preprocessing simple and
the results reliable.

\textbf{Task for this lab:} predict \textbf{Cannabis use (User vs
Non-user)} from: - Big Five personality traits (NEO-FFI-R):
\texttt{nscore} (neuroticism), \texttt{escore} (extraversion),
\texttt{oscore} (openness), \texttt{ascore} (agreeableness),
\texttt{cscore} (conscientiousness) - Impulsivity (\texttt{impulsive},
BIS-11) and sensation seeking (\texttt{ss}, ImpSS) - Demographics:
\texttt{age}, \texttt{gender}, \texttt{education}, \texttt{country},
\texttt{ethnicity}

We implement Decision Tree and Random Forest classifiers, evaluate with
accuracy / precision / recall / F1-score / confusion matrix, experiment
with key hyperparameters, and compare feature importance, training time,
and generalization behavior.

    \subsection{2. Preprocessing}\label{preprocessing}

The 12 predictor columns are already numeric --- no missing values, no
encoding needed. The only preprocessing step is binarizing the 7-class
target into \textbf{User (1)} / \textbf{Non-user (0)}, following the
convention from the original paper:

\begin{itemize}
\tightlist
\item
  \texttt{CL0} (Never Used), \texttt{CL1} (Used over a Decade Ago)
  -\textgreater{} \textbf{Non-user (0)}
\item
  \texttt{CL2}--\texttt{CL6} (used within the last decade / year / month
  / week / day) -\textgreater{} \textbf{User (1)}
\end{itemize}

    \subsection{7. Hyperparameter experiments --- Decision
Tree}\label{hyperparameter-experiments-decision-tree}

\textbf{\texttt{max\_depth}} controls how many splits the tree can make.
- Shallow trees (2--3) underfit slightly, but train/test accuracy stay
close together. - As depth grows, train accuracy climbs toward 100\%
while test accuracy plateaus and then dips slightly --- the classic
overfitting curve. - \texttt{max\_depth=None}: the tree perfectly fits
the training data but generalizes worse than a moderately-pruned tree.

\textbf{\texttt{min\_samples\_split}} is the minimum number of samples
required to split an internal node. - Low values (2) allow very
fine-grained splits -\textgreater{} overfitting. - Higher values
(50--100) regularize the tree --- training accuracy drops a little, but
test accuracy is often equal to or better.

\textbf{\texttt{criterion}} (\texttt{gini}, \texttt{entropy},
\texttt{log\_loss}) is the impurity measure used to choose each split.
All three usually produce similar test accuracy on this dataset;
entropy/log-loss occasionally edge out gini slightly because they weight
class probabilities more evenly, but the effect is much smaller than
\texttt{max\_depth} or \texttt{min\_samples\_split}.

    \subsection{8. Hyperparameter experiments --- Random
Forest}\label{hyperparameter-experiments-random-forest}

\textbf{\texttt{n\_estimators}} is the number of trees averaged/voted
over. Accuracy improves quickly from 10 -\textgreater{} 50
-\textgreater{} 100 trees, then plateaus with diminishing returns.
Training time scales roughly linearly with the number of trees.

\textbf{\texttt{max\_depth}} has the same meaning as in a single tree,
but because each tree only sees a bootstrap sample and a random subset
of features, individual trees can go much deeper before the
\emph{ensemble} starts overfitting --- the forest is far more resistant
to depth-driven overfitting than a lone Decision Tree.

\textbf{\texttt{max\_features}} is the number of features considered at
each split. \texttt{sqrt}/\texttt{log2} de-correlate the trees by
forcing each split to consider only a random feature subset, generally
giving the best or near-best generalization. \texttt{max\_features=None}
(all features every split) makes trees more correlated with each other,
reducing the variance-reduction benefit of bagging.

\textbf{Conclusion:} the Random Forest is the better-performing model
for this dataset on F1-score, and is noticeably more robust to
hyperparameter choices --- but the single Decision Tree remains valuable
when interpretability (e.g., explaining \emph{why} someone was flagged
as higher-risk) matters more than raw predictive performance. Feature
importance analysis on both models points to \textbf{sensation seeking}
and \textbf{impulsivity} as the strongest personality-based predictors
of cannabis use, consistent with prior psychological research.
