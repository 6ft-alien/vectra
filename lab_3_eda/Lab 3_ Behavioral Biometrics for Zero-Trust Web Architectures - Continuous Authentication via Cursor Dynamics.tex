\subsubsection{1. Introduction \& Research
Problem}\label{introduction-research-problem}

Static perimeter authentication (e.g., passwords, SMS/TOTP MFA, and
static JSON Web Tokens) implicitly trusts a user after the initial
point-of-entry login. This paradigm creates critical vulnerabilities: -
\textbf{Workstation abandonment / physical walk-away:} An authenticated
session remains vulnerable to unauthorized physical access. -
\textbf{Session token hijacking:} If an active JWT or session cookie is
stolen, attackers inherit complete access without re-verification.

\textbf{Research Objective:} Continuous, passive identity verification
using \textbf{Behavioral Biometrics}---specifically, cursor dynamics
(velocity, acceleration, jerk, angular curvature, click cadence, and
pause patterns). By continuously modeling interaction micro-dynamics,
anomalous behavioral deviations trigger instant token revocation under a
Zero-Trust Architecture (ZTA).

This Exploratory Data Analysis (EDA) investigates the \textbf{Balabit
Mouse Dynamics Challenge} benchmark dataset: - \textbf{10 unique user
accounts} - \textbf{Training set:} 65 extensive baseline sessions
(\textasciitilde2.25 million events) known to belong to authentic owners
- \textbf{Test set:} 1,611 realistic evaluation sessions
(\textasciitilde2.35 million events) containing mixed authentic and
imposter sessions - \textbf{Ground truth:} \texttt{public\_labels.csv}
(0 = Legitimate owner, 1 = Simulated imposter/illegal)

elapsed time (seconds) - \texttt{button}: Mouse button state
(\texttt{NoButton}, \texttt{Left}, \texttt{Right}, \texttt{Scroll}) -
\texttt{state}: Action event state (\texttt{Move}, \texttt{Pressed},
\texttt{Released}, \texttt{Drag}) - \texttt{x}, \texttt{y}: Screen
cursor Cartesian coordinates (pixels)

(drag events / total events). 4. \textbf{Cognitive Hesitation \&
Pauses:} Pause events count (\(\Delta t > 0.5s\) with movement
\(< 5px\)), pause ratio. 5. \textbf{Spatial Geometry:} Path straightness
ratio (total cumulative path / Euclidean displacement), spatial spread
(\(x_{\text{std}}, y_{\text{std}}\)).
